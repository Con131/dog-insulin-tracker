Доступ по ссылке

Дневник откроется по секретной ссылке. Люди, у которых она есть, смогут смотреть, добавлять и изменять записи.

Открыть дневник по ссылке

Эта GitHub Pages страница общедоступна. Не вводите здесь данные об инъекциях. В закрытой таблице прямой доступ останется ограниченным, но любой, у кого есть ссылка на Apps Script, сможет читать и менять дневник. Передавайте её только доверенным людям.

Найдены записи из старой версии

Они остались только в хранилище этого браузера и автоматически в таблицу не переносились. Скачайте копию, если нужно перенести эти записи, затем удалите старые данные с публичного сайта.

Как настроить один раз

  1. Откройте свою таблицу → Расширения → Apps Script.
  2. Вставьте содержимое Code.gs. Создайте HTML-файл с именем index и вставьте туда содержимое index.html.
  3. Запустите setupTrackingSheet и разрешите доступ к таблице.
  4. Нажмите Развернуть → Новое развертывание → Веб-приложение. Выберите «Выполнять от имени: Я», а доступ — Все, у кого есть ссылка.
  5. Скопируйте URL /exec, вставьте выше и откройте дневник.

Подробная инструкция по таблице, закрытию старых развертываний, обновлению и защите ссылки: открыть полный мануал.

Ссылка работает как пароль. Не публикуйте её в открытом доступе. Таблицу отдельно оставьте с доступом «Ограниченный».

Публичная страница не читает и не отправляет медицинские записи. Вводите данные только в закрытом Google-приложении.
