# Инсулин-пёс

**Публичная стартовая страница:** https://con131.github.io/dog-insulin-tracker/

Инсулиновые записи не отправляются на GitHub Pages. Для дневника создаётся личное веб-приложение Google Apps Script: его серверная часть читает таблицу только из авторизованного Apps Script, а браузер вызывает сервер через `google.script.run`. Здесь нет публичных `doPost`, JSON или JSONP API.

## Настройка личного дневника (один раз)

### 1. Закройте доступ к таблице

Откройте [свою таблицу](https://docs.google.com/spreadsheets/d/10HzH-zEU-aO1zhxWQqrTx93quhEtbF1nBT7pZuZAT04/edit). Нажмите **Настройки доступа / Поделиться** и проверьте:

- **Общий доступ** установлен как **Ограниченный**, не «Все, у кого есть ссылка».
- В списке доступа оставлены только ваш Google-аккаунт и люди, которым вы действительно доверяете.

### 2. Создайте Apps Script

В таблице откройте **Расширения → Apps Script**.

1. В редакторе `Code.gs` замените содержимое файлом [`Code.gs`](Code.gs).
2. Нажмите `+` рядом с «Файлы», выберите **HTML**, назовите файл `index` (именно `index`, без `.html`) и вставьте туда целиком содержимое [`index.html`](index.html).
3. Сохраните проект. Выберите `setupTrackingSheet` в списке функций и нажмите **Выполнить**. Проверьте запрашиваемые Google разрешения и подтвердите доступ к таблице. Скрипт создаст лист `Инъекции`, не удаляя остальные листы.

### 3. Разверните только для себя

В редакторе нажмите **Развернуть → Новое развертывание → Веб-приложение**:

| Настройка | Выберите |
| --- | --- |
| Выполнять от имени | **Я** |
| У кого есть доступ | **Только я** |

Нажмите **Развернуть**, пройдите авторизацию и скопируйте URL, который заканчивается на `/exec`.

### 4. Откройте личный дневник

Откройте публичную стартовую страницу выше, вставьте скопированный `/exec` URL и нажмите **Открыть личный дневник**. Войдите в Google под тем же аккаунтом, который создал и развернул скрипт. Добавьте личную страницу в закладки.

В дальнейшем открывайте сохранённую личную ссылку Google Apps Script. GitHub Pages — только общедоступная страница-помощник; она не содержит записи и не обращается к таблице.

## Если ранее создавалось открытое развертывание

В Apps Script нажмите **Развернуть → Управление развертываниями**. Архивируйте старые веб-развертывания, у которых доступ был **Все** или **Все, у кого есть аккаунт Google**, затем создайте описанное выше развертывание **Только я**. В Google Таблице отдельно проверьте режим «Ограниченный» и удалите неизвестных участников. Если таблица или URL когда-либо были доступны посторонним, считайте уже просмотренные данные раскрытыми; простое изменение URL не отменяет прошлый доступ.

## Границы защиты и резервная копия

- Права Google Apps Script и таблицы ограничивают просмотр и изменение записей вашим аккаунтом. Сам код приложения на публичном GitHub Pages виден всем — в нём нет паролей, токенов или данных таблицы. Не меняйте доступ веб-приложения на публичный.
- После авторизации дневник кеширует данные в локальном хранилище браузера для мгновенного отображения и очереди повторной синхронизации. Защитите устройство блокировкой экрана; после использования на общем устройстве очистите данные сайта Google Apps Script в настройках браузера.
- GitHub Pages остаётся публичным сайтом. Настоящий дневник открывается в Google Apps Script и требует аккаунт владельца; поскольку Google Apps Script сам обслуживает личную страницу, полноценная офлайн-установка оболочки PWA браузером не гарантируется. Несинхронизированные записи хранятся локально и отправляются после восстановления связи и открытия личного приложения.
- Таблица Google — основная резервная копия после синхронизации. Можно дополнительно скачать копию через **Файл → Скачать**. Периодически проверяйте, что очередь ожидающих записей исчезла после подключения.
- Напоминание на 12 часов не является назначением лечения. Дозу и расписание определяет ветеринарный врач.
