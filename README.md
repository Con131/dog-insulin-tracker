# Инсулин-пёс — дневник по секретной ссылке

Публичная страница настройки: **https://con131.github.io/dog-insulin-tracker/**

Таблица: [открыть Google Таблицу](https://docs.google.com/spreadsheets/d/10HzH-zEU-aO1zhxWQqrTx93quhEtbF1nBT7pZuZAT04/edit)

GitHub Pages — общедоступная памятка. Записи вводятся только в отдельное приложение Google Apps Script. Таблицу можно закрыть от прямого доступа, а само приложение настроить для всех, у кого есть его ссылка. **При таком режиме ссылка фактически становится паролем:** любой обладатель URL `/exec` сможет читать, добавлять и редактировать записи, причём приложение выполняется от имени владельца таблицы. Передавайте URL только тем, кому доверяете.

## 1. Отзовите старую ссылку и проверьте таблицу

Старая версия приложения использовала публичный JSON endpoint. Его нельзя использовать для новых записей.

1. В таблице откройте **Расширения → Apps Script**.
2. Откройте **Развернуть → Управление развертываниями**.
3. Архивируйте старое веб-развертывание. Это отключит старую ссылку и старый endpoint.
4. В самой таблице нажмите **Поделиться** и установите **Общий доступ: Ограниченный**. Удалите людей, которым доступ больше не нужен.
5. Если старый URL раньше был доступен посторонним, архивируйте его немедленно. Это не отменит данные, которые могли быть просмотрены или сохранены раньше.
6. На каждом устройстве, где раньше пользовались дневником, откройте публичную страницу настройки. Если найден локальный кэш старой версии, сначала нажмите **Скачать локальную копию**, проверьте файл и перенесите нужные записи, затем нажмите **Удалить старые данные**. Публичная страница покажет только количество старых записей, а не их значения.

## 2. Установите код в Apps Script

Войдите в Google под аккаунтом, который имеет право редактировать таблицу, откройте таблицу и выберите **Расширения → Apps Script**.

1. Откройте файл `Code.gs`. Замените его содержимое текстом из [Code.gs](https://github.com/Con131/dog-insulin-tracker/blob/main/Code.gs): на странице файла нажмите **Raw / Исходный код**, выделите всё и скопируйте в редактор.
2. Нажмите **+** рядом со списком файлов и выберите **HTML**.
3. Назовите новый HTML-файл `index` (ровно это имя, без `.html`). Вставьте всё содержимое [index.html](https://github.com/Con131/dog-insulin-tracker/blob/main/index.html) через **Raw / Исходный код**.
4. Сохраните оба файла (`Ctrl+S`).

`Code.gs` уже настроен на ID вашей таблицы. Если старый лист `Инъекции` есть, данные сохранятся; к нему добавится колонка «Кто сделал запись». Другие листы не удаляются.

## 3. Создайте лист и выдайте разрешение

1. В верхнем списке функций Apps Script выберите `setupTrackingSheet`.
2. Нажмите **Выполнить**.
3. Выберите свой аккаунт и подтвердите запрошенный доступ скрипта к Google Таблице.
4. Внизу откройте **Журнал выполнения**. Убедитесь, что запуск завершился успешно и в таблице есть лист `Инъекции`.

Если Google показывает предупреждение «Приложение не проверено», продолжайте только если вы находитесь в собственном Apps Script-проекте: **Дополнительные настройки → Перейти к проекту**. Не давайте разрешения незнакомому скрипту.

## 4. Разверните дневник по ссылке

1. В Apps Script нажмите **Развернуть → Новое развертывание**.
2. Нажмите ⚙️ и выберите тип **Веб-приложение**.
3. В поле **Выполнять от имени** выберите **Я**. Так посетителям ссылки не нужен прямой доступ к таблице.
4. В поле **У кого есть доступ** выберите **Все (Anyone / Anyone, even anonymous)**. Это режим «доступ по ссылке», включая людей без Google-аккаунта. Не выбирайте вариант только для пользователей Google, если нужен доступ без входа.
5. Нажмите **Развернуть** и подтвердите разрешения.
6. Скопируйте URL веб-приложения, который заканчивается на `/exec`. Сохраните его как секретную ссылку и отправляйте только нужным людям.

Если варианта **Все (Anyone)** нет, проверьте ограничения Google Workspace. Не публикуйте таблицу, чтобы обойти это ограничение: попросите администратора настроить политику Apps Script или используйте аккаунт/сервис, где разрешено нужное веб-развертывание.

## 5. Откройте приложение

1. На странице [инструкции](https://con131.github.io/dog-insulin-tracker/) вставьте URL `/exec` и нажмите **Открыть дневник**. Медицинские записи на страницу GitHub Pages не вводятся.
2. Сохраните URL `/exec` в закладки. Этот же URL можно передать другим доверенным пользователям.
3. Создайте тестовую запись: задайте автора, сохраните запись и проверьте новую строку на листе `Инъекции`.
4. На телефоне можно сохранить URL `/exec` на главный экран: iPhone — Safari → **Поделиться → На экран «Домой»**; Android — меню браузера → **Добавить на главный экран**. Доступ к таблице требует интернета; PWA-установка зависит от браузера.

## Обновление

Замените `Code.gs` и содержимое HTML-файла `index` по шагам 2–3, затем сохраните проект. Откройте **Развернуть → Управление развертываниями**, нажмите ✏️ у используемого развертывания, выберите **Новая версия** и нажмите **Развернуть**. URL `/exec` обычно не меняется. Проверьте, что выставлено **Выполнять от имени: Я** и **Доступ: Все (Anyone)**. Старые опубликованные версии с JSON endpoint архивируйте.

## Автор записи, редактирование и мобильный экран

- Поле **Кто сделал запись** обязательно. Имя запоминается в браузере для следующих записей; перед сохранением его можно поменять. В таблице и истории отображается автор каждой записи.
- Кнопка **Изменить** загружает строку в форму. Сохранение обновляет ту же строку по её ID, включая автора, не создавая дубликат.
- При временной потере соединения новая или изменённая запись остаётся в локальной очереди и синхронизируется при повторном открытии приложения/подключении к сети. Дождитесь статуса успешной синхронизации.
- На листах старой версии имя автора будет пустым; старые значения и строки не удаляются.

## Что защищено, а что нет

- Таблица Google остаётся с общим доступом **Ограниченный**. Не включайте «Все, у кого есть ссылка» для таблицы.
- У веб-приложения установлен доступ **Все (Anyone)** по прямому требованию доступа без входа. **Каждый, у кого есть URL `/exec`, может читать и изменять медицинские записи через приложение.** Это bearer-ссылка, а не персональная авторизация или надёжная защита от передачи адреса.
- Код на GitHub Pages публичный, но сам не загружает и не показывает историю. Не добавляйте в публичный репозиторий URL веб-приложения, записи, скриншоты с данными или резервные копии.
- Чтобы прекратить доступ, в Apps Script архивируйте развертывание и создайте новое с другим URL. Если ссылка утекла, сделайте это сразу; удаление старой ссылки не отменяет просмотренные ранее данные.
- На публичной стартовой странице можно проверить старый локальный кэш, скачать его копию и удалить. В новом личном приложении история и очередь для офлайн-отправки хранятся в локальном хранилище профиля браузера; защитите устройство блокировкой экрана и не оставляйте приложение открытым на чужом устройстве.
- После подтверждённой синхронизации Google Таблица служит основной копией. Периодически скачивайте резервную копию через **Файл → Скачать**.
